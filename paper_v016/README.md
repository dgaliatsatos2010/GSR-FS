# GSR-FS v0.16 manuscript-readiness package

This folder is generated from the frozen v0.16 research package and completed v0.14 heterogeneous canonical evidence. It does **not** add new empirical results.

Use:
- `MANUSCRIPT_CORE_V016.md` for a publication-oriented Methods/Results/Discussion/Conclusions draft;
- `ABSTRACT_CANDIDATE_V016.md` for an evidence-matched abstract;
- `CLAIM_MATRIX_V016.md` to prevent overclaiming;
- `CC18_FIRST_RUN_ACCEPTANCE_CHECKLIST_V016.md` after the GitHub Actions run;
- `tables/` for manuscript tables;
- `PAPER_READINESS_STATUS_V016.json` as the machine-readable submission-status gate.

The manuscript is draft-ready, but final standardized-suite claims remain conditional on the official OpenML-CC18 and recent-author runs.
