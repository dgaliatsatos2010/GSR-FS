# Data and code availability statement — draft v0.16

All GSR-FS source code, benchmark scripts, test code, frozen configuration files, source-integrity audits, and completed heterogeneous benchmark outputs are prepared for public repository release. The GSR-FS code is MIT-licensed. Third-party comparator source code is not redistributed; canonical and recent-author bridges retrieve or call separately sourced implementations subject to their original licenses and verify pinned source identifiers where applicable.

The completed heterogeneous evidence panel uses publicly available or package-bundled datasets with recorded provenance. The formal OpenML-CC18 confirmation will retrieve tasks from OpenML at execution time rather than redistributing the benchmark datasets. A public repository URL and archival DOI should be inserted here only after the dedicated GSR-FS repository and archival release have actually been created.
