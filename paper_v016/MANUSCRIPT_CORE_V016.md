# Manuscript core — Methods, Results, Discussion, and Conclusions (v0.16 evidence freeze)

## Working title

**Geometry-Supported Residual Feature Selection: Permutation-Calibrated Label-Blind Selection of Complementary Sample Geometry**

## 1. Methods

### 1.1 Problem formulation

Let $X\in\mathbb{R}^{n\times p}$ denote a predictor matrix. GSR-FS is designed for unsupervised feature selection: the selector is not allowed to receive the outcome vector $y$, the ground-truth number of classes, or any hyperparameter chosen from performance against the final labels. Labels are used only after feature selection for downstream evaluation.

For feature $j$ and samples $a,b$, its additive squared-distance contribution is

$$
g_j(a,b)=(x_{aj}-x_{bj})^2.
$$

Because squared Euclidean distance decomposes additively across features,

$$
\|x_a-x_b\|_2^2=\sum_{j=1}^{p}g_j(a,b),
$$

$g_j$ provides a feature-specific geometry profile over sample pairs. GSR-FS evaluates whether that profile contains reproducible structure and whether it adds geometry not already represented by selected features.

### 1.2 Robust preprocessing and pair geometry

The frozen implementation uses robust centering/scaling with median/MAD handling and clipping at $|z|=4.5$. When all sample pairs are computationally impractical, pair geometry is approximated using balanced nested pair sampling. The balanced sampler uses a randomized round-robin schedule so that endpoint participation is approximately uniform; for a fixed seed, smaller pair budgets are prefixes of larger budgets. Pair-sampling randomness and permutation-calibration randomness use independent random-number streams.

### 1.3 Permutation-calibrated structural support

For each feature, the observed geometry profile is compared with within-feature permutation null profiles generated without labels. A common bank of sample-index permutations is reused across features. The resulting support statistic measures how strongly the feature geometry departs from what would be expected after destroying its sample alignment.

### 1.4 Sample-Geometric Coverage

A large feature-geometry statistic can be driven by very few observations. Sample-Geometric Coverage (SGC) downweights features whose pairwise geometry is concentrated on a small number of sample endpoints. The frozen coverage exponent is 2.0. The product of permutation-calibrated structural support and SGC defines the effective structural support used by the greedy selector.

### 1.5 Complementary geometry through non-negative residual projection

Let $S$ denote the set of already selected features. For candidate feature $j$, GSR-FS projects its geometry profile onto the cone generated by geometry profiles in $S$ using non-negative coefficients. The normalized unexplained component is denoted $R(j\mid S)$. Values near 0 indicate that the candidate geometry is largely reproducible from selected features, whereas values near 1 indicate complementary geometry.

The frozen greedy criterion is

$$
Score(j\mid S)=EffectiveSupport_j\,R(j\mid S)^{0.5}.
$$

The exponent 0.5 was frozen in v0.5 using simulation and a small development set before the later 30-dataset evidence panel. No final-panel label was used to retune this value.

### 1.6 Automatic subset-size selection

In automatic mode, GSR-FS constructs a feature-wise permutation null and a max-null distribution across features. The $(1-\alpha)$ quantile of the max-null distribution provides an automatic stopping threshold; $\alpha=0.05$ is frozen. The procedure permits zero selected features when no candidate exceeds the threshold. Final automatic-mode inference specifies 200 permutations; lower permutation counts were used only in explicitly identified runtime/development experiments.

### 1.7 Structural substitution diagnostic

Later releases added Contextual Geometry Substitution (CGS) as a diagnostic layer, not as a change to the frozen selector. CGS asks whether a non-selected feature can replace a selected representative inside the selected geometry basis without substantial loss of representation. The frozen diagnostic threshold is 0.85. Group output therefore reports alternative structural representatives while `transform()` continues to return the original selected columns; no latent feature or feature extraction step is created.

### 1.8 Comparator implementations

The final heterogeneous canonical panel used independently sourced scikit-feature implementations of Laplacian Score, SPEC, and MCFS, together with MaxVariance. Third-party GPL source was not vendored into the MIT GSR-FS package. The upstream scikit-feature repository and individual source blobs were source-locked. MCFS used its upstream default of five clusters rather than the ground-truth class count. A compatibility workaround for the upstream Laplacian Score path explicitly supplied the graph produced by the same upstream `construct_W(X)` function to the same upstream `lap_score` function.

### 1.9 Dataset source-integrity policy

A dataset counted toward external evidence only when the feature matrix reaching the unsupervised selector had not already been filtered, sampled, or transformed using the target. Target-informed feature importance, class-stratified data reduction, target-informed preprocessing, and unresolved provenance were exclusion criteria. Ordinary label-blind imputation, encoding, scaling, and uniform row subsampling were permitted and recorded. The heterogeneous evidence panel contains 30 source-integrity-PASS datasets; 29 have complete results for all five compared methods.

### 1.10 Downstream evaluation and statistical analysis

Feature selection was performed within the training portion of downstream evaluation rather than on the entire dataset. Balanced accuracy was treated as the principal downstream classification summary in the final canonical aggregation, with macro F1 and accuracy as secondary metrics. Repeated observations within a dataset/method were aggregated before cross-dataset analysis so that each dataset received equal weight.

For complete multi-method comparisons, dataset-wise ranks were analyzed using the Friedman test. Pairwise GSR-FS-versus-competitor comparisons used paired Wilcoxon tests, Holm multiplicity adjustment, and paired rank-biserial effect sizes. Non-significant results were not interpreted as evidence of equivalence.

## 2. Results

### 2.1 Automatic-selection calibration

In 200 independent-null simulations at nominal $\alpha=0.05$, 13 runs selected at least one feature, corresponding to empirical family-wise false selection of 0.065. The exact 95% binomial interval previously calculated for this estimate was approximately 0.035–0.109, which includes 0.05. This result is consistent with approximate calibration but is not a proof of finite-sample family-wise error control.

In 30 redundant-signal simulations, automatic GSR-FS selected exactly two features in every run. Mean latent-group coverage was 1.00, relevant-feature precision was 1.00, and redundancy was 0.00. In contrast, a coherent-outlier diagnostic produced mean selected subset size 21.8 and relevant precision approximately 0.092 despite group coverage of 1.00, demonstrating an important unsupervised identifiability limitation.

### 2.2 Canonical heterogeneous real-data comparison

Across the 29 datasets with complete canonical comparisons, GSR-FS achieved mean balanced accuracy 0.6031 (SD 0.2425) and mean rank 2.862. SPEC had mean balanced accuracy 0.6019 (SD 0.2251) and the best mean rank, 2.690. MaxVariance, MCFS, and Laplacian Score obtained mean balanced accuracies 0.5892, 0.5970, and 0.5810, respectively. Thus GSR-FS had the highest arithmetic mean balanced accuracy but not the best cross-dataset rank.

The Friedman omnibus test for balanced accuracy was not significant ($p=0.4880$). No GSR-FS pairwise comparison was significant after Holm correction. The Holm-adjusted $p$ values against Laplacian Score, MCFS, and SPEC were approximately 0.331, 1.000, and 1.000, respectively. Therefore the current evidence does not establish overall statistical superiority.

For macro F1, GSR-FS achieved the highest arithmetic mean (0.5816), while MaxVariance had the best mean rank (2.724). The Friedman test was again non-significant ($p=0.3867$). For accuracy, GSR-FS and SPEC tied for the best mean rank (2.828), with mean accuracies 0.6061 and 0.6064; the Friedman test was non-significant ($p=0.7712$).

### 2.3 Information-level stability diagnostics

CGS analyses showed that exact-column instability can overstate information-level instability when multiple variables act as contextual substitutes. In fresh label-free structural diagnostics, mean exact-column Jaccard across Longley, Macrodata, and Diabetes was approximately 0.603, compared with approximately 0.782 for structural-group-aware stability. The gain was concentrated in datasets with clear substitute structures; Diabetes produced no non-singleton group and no artificial stability increase.

### 2.4 Computational approximation diagnostics

Balanced pair sampling converged toward exact all-pairs rankings more reliably than random pair sampling at low and moderate pair budgets. On Iris, Wine, and Breast Cancer, mean rank correlation to exact geometry at 20,000 pairs was approximately 0.948 for balanced sampling versus 0.888 for random sampling. The optimized residual engine also removed a runtime cliff: on Breast Cancer at 20,000 pairs, batched coordinate descent reduced the measured residual-stage runtime from approximately 6.26 s to 0.64 s while preserving the selection path to numerical precision.

## 3. Discussion

The completed evidence supports a narrower conclusion than a state-of-the-art claim. GSR-FS is competitive with classic canonical unsupervised selectors while optimizing a distinct structural objective: reproducible and complementary contributions to sample geometry. Its arithmetic mean balanced accuracy was marginally higher than SPEC in the heterogeneous complete-case panel, but SPEC ranked better across datasets and the omnibus and post-hoc analyses were non-significant. The method should therefore be presented as a competitive alternative with different inductive bias, not as a demonstrated replacement for Laplacian Score, SPEC, MCFS, or newer UFS methods.

The simulation results identify two attractive properties. First, the automatic max-null mode can return an empty set and showed approximate null calibration. Second, the residual term strongly suppresses redundant representatives in controlled signal families. However, these strengths do not guarantee alignment with downstream class labels. A feature can preserve broad sample geometry while being weakly discriminative for a particular outcome, and coherent rare structure can be indistinguishable from meaningful rare subgroups without additional assumptions.

The CGS diagnostic clarifies another issue. Exact feature identity is not always the right definition of stability in redundant data: different resamples may select different representatives of nearly interchangeable geometry. Reporting both exact-column stability and contextual substitution-aware stability provides a more informative account, while leaving the actual selected subset unchanged.

## 4. Limitations

1. The completed 30-dataset panel is heterogeneous and source-audited but is **not** an official OpenML-CC18 suite-99 execution.
2. The current complete canonical comparison covers 29 datasets, not all 30, because the retained Digits result is outside the complete dense-spectral author-code set.
3. The strongest current comparators are classic canonical methods; a recent 2026 author-code FGMRW-UFS bridge is source-audited and predeclared but has not yet been empirically executed in the present offline runtime.
4. The automatic-mode null study provides empirical calibration evidence, not a formal theorem.
5. Coherent outlier/minority structure remains an unsupervised identifiability problem.
6. Pair subsampling is an approximation; although balanced sampling improves convergence, exact all-pairs selections can still differ at finite budgets.
7. The present evidence does not support claims of state-of-the-art performance or universal replacement of existing selectors.

## 5. Conclusions

GSR-FS provides a fully label-blind feature-selection framework based on permutation-calibrated structural support and complementary sample geometry. Across a source-audited 30-dataset evidence panel, with 29 complete comparisons against canonical Laplacian Score, SPEC, MCFS, and MaxVariance, its downstream performance was competitive but not statistically superior. The method therefore warrants presentation as a distinct, reproducible unsupervised feature-selection approach rather than as a universal replacement for established techniques. The predeclared next confirmatory step is execution of the frozen v0.16 protocol on official OpenML-CC18 tasks together with a pinned recent-author FGMRW-UFS comparison, without retuning the GSR-FS objective on those final tasks.
